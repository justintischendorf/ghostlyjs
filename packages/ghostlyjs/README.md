# ghostlyjs

> 🚧 **Work in progress.** This package is not usable yet.

Auto-generate skeleton loaders for React by measuring your real UI.
No more hand-written skeletons.

```tsx
<Ghostly name="member-cards" loading={isLoading}>
  <MemberCards />
</Ghostly>
```

Follow the progress on [GitHub](https://github.com/justintischendorf/ghostlyjs).
